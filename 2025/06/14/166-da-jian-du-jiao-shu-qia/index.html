环境

  • (PHP + PHPCLI) version = 7.4
    • *安装fileinfo扩展
    • *安装redis扩展
    • *终端需支持php-cli，测试php -v(版本必须一致)
    • *需要开启的函数：putenv，proc_open，pcntl_signal，pcntl_alarm
    • 安装opcache扩展
  • Nginx version >= 1.16
  • MYSQL version >= 5.6
  • Redis (高性能缓存服务)
  • Supervisor (一个python编写的进程管理服务)
  • Composer (PHP包管理器)
  • Linux (Win下未测试，建议直接Linux)

问题

php7.4无法安装

Ubuntu 22.04 及以后版本官方仓库只提供 PHP 8.1+，要装 PHP 7.4 需要加第三方源。

方案 A：添加 Ondřej Surý 的 PPA，安装 PHP 7.4

  1. 安装添加 PPA 的工具

  2. 添加 Ondřej Surý 的 PHP 源

  3. 安装 PHP 7.4 及扩展

  4. 切换系统默认 php（可选，但强烈推荐）

  5. 回到项目目录，重装依赖并缓存配置

这样就能正常生成 vendor/autoload.php 并运行 php artisan 系列命令。

mysql的密码强度
