ESP32 C3 蓝牙网关接入 Home Assistant

本文记录用 ESP32-C3 把米家温湿度计 3 mini 接入 Home Assistant 的过程。家里要放两个 3 mini，表只发蓝牙 BLE 广播，Home Assistant 装在荷兰的服务器上，蓝牙够不到，所以中间加了一个 ESP32-C3 作蓝牙网关：它在家里收蓝牙广播，通过网络转给 HA。

链路

  • C3 开发板型号 esp32-c3-devkitm-1，局域网固定 IP 192.168.31.50
  • 泰山派只做转发，socat 把 6053 端口转给 C3
  • HA 跑在 NL 的 Docker 里，地址是 NL 的 Tailscale IP 100.79.204.105:8123，8123 只绑 Tailscale，不对外
  • NL 到家里的 ping 平均约 757ms，温度约两分钟变一次，这个延迟不影响数据

网关方案的选择

ESPHome 接米家表有两种办法：

  1. 直连解码：C3 上跑 xiaomi_ble 等原生平台，直接读出温湿度。之前给米家 Pro（LYWSD02MMC）写过这种配置，需要表的 MAC 和 bindkey。
  2. 蓝牙代理：C3 用 bluetooth_proxy 把广播原样转给 HA，由 HA 的 Xiaomi BLE 集成解码。

遇到的问题

1. HA 装泰山派行不通

最初打算把 HA 装在泰山派上。板子的 6.1.75 内核没编入 POSIX 消息队列（CONFIG_POSIX_MQUEUE），Docker 起任何容器都会在挂载 /dev/mqueue 时失败。之前 netfilter 和 overlayfs 被裁掉还能绕开，这次没找到绕开的办法。结论是这块板子的内核跑不了 Docker 容器，HA 改装在 NL，板子只做转发。

2. web.esphome.io 的 Install 框没有 YAML 输入处

刷机用 Chrome 打开 web.esphome.io 即可。我原以为 Install 框能粘贴 YAML，实际只能选 .bin 文件。最后在本地编译出一个 1.36 MB 的工厂镜像，编译零错误，在 Install 框里选文件刷入。Wi-Fi 配网信息存在 C3 里，重刷后还在。

3. 第一次刷成了默认固件

第一次刷的是 web.esphome.io 的默认固件，设备名 esphome-web-d183d4，不含蓝牙代理。它能连上 HA，HA 里也能看到设备，但温度计的数据收不到。换成上面那份代理配置重刷后，设备名变成 c3-bluetooth-proxy，HA 里原来那台设备掉线，重新配置时填了新的 API key。

4. mDNS 跨不过 Tailscale

HA 和 C3 不在同一个局域网，mDNS 发现不起作用，在 HA 里手动添加了 ESPHome 设备：主机填板子的 Tailscale IP 100.65.29.115，端口 6053。C3 的固定 IP 192.168.31.50 只在板子上的 socat 转发里用到，HA 那边填的是板子的 Tailscale 地址。

5. HA 页面报 502

HA 装好后浏览器打开显示 HTTP ERROR 502。NL 上查过，容器正常，页面返回 200，日志没有报错。原因在电脑端：Clash 把 100.64.0.0/10（Tailscale 网段）也送去了代理节点，远端节点连不到这个内网地址。给 Clash 加一条 100.64.0.0/10 走 DIRECT 的规则后恢复。

实测结果

  • 整条链路已通：C3 在 HA 里出现过，socat 转发、Tailscale、HA 添加设备三步都验证过。
  • 3 mini 的广播间隔约 2 分钟，不是按一下按钮才发一次，但间隔偏长。要更快的话，可以给表刷 pvvx 第三方固件，间隔可调，这一项没有实测。
  • 3 mini 的广播是加密的。进 HA 后 Xiaomi BLE 集成会要 bindkey，可用 Xiaomi-cloud-tokens-extractor 从小米云端获取，不影响米家 App 使用。刷 C3 固件这一步不需要 bindkey。
  • C3 作代理后，蓝牙覆盖范围内的其他蓝牙设备，如门窗传感器、蓝牙锁，HA 一般也能直接发现，不用每个设备配一个网关。这一项没有实测。

当前状态

网关侧已就绪，代理固件已编译，链路已验证。3 mini 尚未到货通电，到货后 HA 的 Xiaomi BLE 集成会自动发现，再填 bindkey 即可出数据。3 mini 目前独立使用，看屏幕和米家 App 近场读数。

附注

  • ESP32-C3 只支持 2.4G Wi-Fi，配网时连的是 2.4G SSID。
  • 刷机用的 USB 线有些只能充电，不能传数据。web.esphome.io 弹不出串口时换过线。
