使用 RKDevTool 烧录

update.img 是完整 Rockchip 升级包，不需要手动填写各分区地址。

  1. 将 rockdev/update.img 复制到 Windows。
  2. 泰山派进入 Loader 或 Maskrom 模式并连接 USB OTG。
  3. RKDevTool 底部显示“发现一个 LOADER 设备”。
  4. 进入“升级固件”页，点击“固件”，选择 update.img。
  5. 等待固件信息解析完成，点击“升级”。
  6. 等待成功提示，不要断电或拔 USB。

不要把 update.img 填到“下载镜像”页的某个地址；手工地址烧录适用于拆分的 MiniLoaderAll.bin、uboot.img、boot.img、rootfs.img 等文件。

常见问题速查

  • gcc ... -mlittle-endian：交叉编译器未生效，重新 export CROSS_COMPILE。
  • recovery.img open file failed：打包清单包含不存在的 Buildroot recovery，注释 recovery 条目。
  • rootfs.img open file failed：没有生成 rockdev/rootfs.ext4，先制作 ext4 镜像。
  • RKDevTool 显示 RK3568：RK356x SDK 共用元数据，确认 U-Boot 为 rk3566、DTS 为 tspi-rk3566-user-v10-linux 即可。
  • 无 Wi-Fi：先看 dmesg 是否有 SDIO、固件路径和 GPIO 电源域错误，再确认 bcmdhd.ko、fw_bcmdhd.bin 和 nvram.txt 均存在。
  • failed ... fw_bcm43438a1.bin：驱动自动选中了 A1，但镜像只放了通用文件名；补齐 fw_bcm43438a1.bin 和 nvram_ap6212a.txt。
  • Authentication token manipulation error：旧镜像的 haxio 账户被设置为首次强制改密，且输入了错误的旧密码或根分区不可写；当前最终镜像已改为 tspi/orangepi2026 并取消强制改密。
  • 音频播放正常、录音失败并出现 rate(0)：检查 I2S1 是否使用 rockchip,trcm-sync-tx-only;，不要继续使用旧的 rockchip,clk-trcm = <1>;。
  • Ubuntu rootfs 空间不足：执行 resize2fs /dev/disk/by-partlabel/rootfs 扩展到参数表的 6 GiB 分区。
