220-示波器焚诀
2903 2026-09-22 17:08:57

调试过程中设备偶发掉电，难以复现，需定位掉电瞬间电源链上先塌陷的节点。本文整理 Rigol DS1202Z-E 示波器的基础操作、SCPI 指令以及抓偶发掉电波形的完整流程，含测点、配置、判读与无人值守方案，并记录调试中确认的固件行为限制。

1. 设备与限制

以下为 Rigol DS1202Z-E 的关键限制，影响方案选型（*IDN? 实测：RIGOL TECHNOLOGIES,DS1202Z-E,DS1ZE271302933）。

项目 情况
通道数 2 通道，多测点需取舍
接电脑 仅后面板 USB Device 口（B 型方口），非 LAN
自动存盘 不支持原生自动存盘，依赖屏幕冻结或电脑轮询
存储深度 大时基下可回放数十秒历史，满足掉电全程观察

注意事项：EXT TRIG IN 非接地端。地线使用探头自带接地钩，接电池负极即可。

3. 基础常用操作

手动读取电压

方法一：按 Measure 键读取测量框显示值。注意本机 MEAS 查询偶发返回 9.9e37 无效值，以脚本日志或数格法为准。

方法二：数格法（可靠）。波形距屏幕中心线上方 X 格，电压 = X × 挡位（V/div），探头 ×10 已折算。

判断示波器工作正常

  1. 屏幕显示两条稳定水平线（约 3.8V 位置）
  2. 右上角状态符合当前模式（Auto / Trig’d / Wait）
  3. 挂脚本时，日志按周期持续刷新

手动存储波形（U 盘）

U 盘插入前面板 USB Host 口，按 Storage 选择 CSV/PNG 导出至外部存储。作为脚本失效时的兜底方案。

恢复默认 / 重新配置

方式一：Utility → 存储 → 出厂设置，之后按第 7 节 SCPI 重建配置。

方式二：直接经上位机逐条发送第 5 节配置命令。

掉电画面识别

  • CH2（SW_VOUT）或 CH1（BQ_VOUT）跌至接近 0
  • 仅青线跌落、黄线保持 3.8V，可判定 AO3401 断开
  • 两线同时跌落，判定前级问题

4. 工作状态与触发原理

Run/Stop 与 Single 两键组合出四种状态，以屏幕右上角标识区分。

状态 进入方式 屏幕标识 掉电捕捉 脚本读波
RUN（连续采集） Run/Stop 绿灯 Auto 否，瞬态一闪而过 可
STOP 再按 Run/Stop 红灯 Stop 定格当前帧，不再捕捉新事件 可读定格帧
SINGLE 武装 Single 橙键 Wait 是，掉电即定格 否，空/超时
NORM 触发 SCPI :TRIGger:SWEEp NORMal Wait/Stop 同 SINGLE 同 SINGLE

Auto 为按键而非状态，按下恢复连续采集，等效 RUN。

核心限制：SINGLE/NORMAL 武装态与波形回读互斥——

结论：武装态不可直接轮询波形。应轮询触发状态位 :TRIGger:STATus?（该查询在 WAIT 态可用），状态由 WAIT 变为 STOP 即表示掉电已被硬件定格，随后再读帧存档。

5. SCPI 指令参考

连接与识别

Windows 经 USBTMC 驱动连接，设备显示为 “USB Test and Measurement Device (IVI)”。脚本使用默认系统 VISA（pyvisa.ResourceManager()），勿用 @py 后端。

触发配置

触发源选择说明：本场景主假设为 AO3401 压降大导致 SW_VOUT（CH2）跌落、而 BQ_VOUT（CH1）保持稳定。若触发源设 CH1，则 CH1 不塌时事件被漏掉。设 CH2 可同时覆盖两类故障——前级故障时 CH2 同样会跟随 CH1 跌破电平，必然触发。

6. 测点与接线

软件链已排尽（WDT 注入实测：INT_WDT 全链后锁存存活、设备正常重启），嫌疑收敛至电源路径。测 AO3401 开关管两端电压，判断掉电根因：

探头 网络 焊接建议
CH1 BQ_VOUT（AO3401 源极） C121/C122/C123 任一 22µF 电容正极
CH2 SW_VOUT（AO3401 漏极） 就近 22µF 电容正极或 TP27 测试点
地夹 ×2 GND 电池座负极，仅夹负极

飞线自元件脚引出，长度控制在 5cm 内，过长引入振铃干扰。

实测参考：SYS 当前约 3.78V（随电池浮动，满电约 4.2V），AO3401 两端压降约 10mV 以内，导通正常。

7. 示波器设置

配置完成后确认状态栏为 Single 且屏幕静止，方可视作待命就绪。

触发源须设 CH2 而非 CH1：本场景主假设为 AO3401 压降大→SW_VOUT 跌落而 SYS 稳定，若触发源盯 CH1，则 CH1 不塌时事件被漏掉。设 CH2 可同时覆盖前级故障（CH2 会跟随 CH1 跌破电平仍会触发）。

8. 波形判读

判断依据（两层）：先看掉电瞬间哪个通道先塌，再看**两通道压差（D-S 压降）**是否异常，后者用于甄别 AO3401 本身。

DS 压差正常值 <10mV（导通良好、Rds(on) 小）。若峰值电流（LTE 发射）期间压差明显放大，指向 AO3401 导通问题。

现象 结论 后续动作
CH1 稳定、CH2 单独跌落，且 D-S 压差放大（数百 mV） AO3401 导通压降大（Rds(on) 高 / Vgs 不足 / 门极受扰）——本场景主嫌疑 二阶段加测门极，改版换管并加门极滤波
CH1 稳定、CH2 断崖式归零 AO3401 几乎关断（门极路径受扰 / 锁存） 核查 GPIO13 / 门极网络
CH1 先塌、CH2 跟随，压差基本不变 前级 BQ25606 或电池补流不足 核查 ILIM 设定 / 电池内阻 / SYS 电容
CH1、CH2 同时跌落、压差不变 负载峰值瞬时电流过大打穿整条电源链 核查 SYS 电容、ILIM、EG800K 峰值电流

注：CH1、CH2 同时跌落且压差保持正常，说明 AO3401 未退化、故障在前级或负载侧，与本场景的“AO3401 压降大”假设不同——两种现象的波形是能够明确区分的。

9. 无人值守方案

偶发故障难点在于人无法持续值守，按条件选择：

方案 A：单次触发冻结——适合短时有人值守。触发即冻结不丢失，返回时屏幕即判定依据。

方案 B：Roll 连续滚动（推荐）——纯示波器即可。时基置于 100ms/div，存储深度取最大，Roll 模式连续记录。设备掉电后信号消失，示波器仍保持运行，最后一段历史稳定于屏幕，返回即可回看掉电前电压变化全貌。优点：不惧误触发、无需手动保存、断电前证据常驻。缺点：大时基下微秒级细节分辨率不足。

建议分两阶段：先以方案 B 确认有无跌落及发生时刻，再以单次触发精修细节。

方案 C：电脑轮询——PyVISA 定时读取 CH1，跌破 3.3V 自动存盘并记录时间戳，可连续数日无人值守，代价是需要常开电脑。

11. 固件行为限制

调试中确认的本机固件行为，直接影响 SCPI 调用方式：

命令 / 模式 实测表现 处理方式
:MEASure:VMIN? CHANnel1 返回 9.9e+37 无效值 弃用测量项查询，改读波形自行计算
:WAVeform:MODE NORMal 仅 60µs 窗口，无法覆盖掉电 改用 MAX：50ms/div 下约 7.8s @20ms/点
:SINGle 后立即读 引擎切换未完成，读超时 等待约 1.5s 后再读
:WAV:DATA? 空头 #9000000000 = 0 字节（WAIT 态） 先切 RUN，或依赖状态位轮询
ASCII 波形首部 首位野值 解析时过滤 0~6V 范围外数据
USB 单连接 Ultra Sigma 与脚本互斥 同一时间仅启用其一

12. 易误判点

  1. 触发方式未设 Normal 时持续刷新，真实事件不可见——确认 Single 且屏幕静止
  2. LTE 常规纹波可能误触发——若为浅跌落且设备未死机，属误触发，重新按 Single/Run
  3. 探头衰减挡需为 ×10（默认），否则 4V 级信号超量程
  4. 示波器独立供电，禁止从被测板取电——设备掉电时示波器须保持供电
  5. UART 录像与波形需保持同一时间轴（以设备时间对齐），方可定位触发场景
  6. 屏幕显示 Wait 时画面静止属正常武装态，非故障
